### 로컬 플레이 로그

- 기능 설명: 테스트 참가자와 버전별 플레이어 입력·상태, 배치 적 상태, 공격 시도·실제 피해 성공을 로컬 JSON Lines 파일로 기록한다.
- 동작 조건 및 처리 흐름: 영속 TelemetryManager와 씬별 TelemetryStageRecorder를 연결한다. 첫 조작 가능 시 시작하고 재도전·다음 스테이지 전환·정상 종료 직전에 구간을 닫는다. 실제 시간만 사용한다. 배치 ID는 에디터에서 발급해 씬에 저장하며 런타임에 생성하지 않는다.
- 구현 상태: 구현 중. 강제 종료 복구·entity_id·스캔 파동/유지 시간 수집은 범위에서 제외한다.

| 파일 경로 | 클래스 / 메서드 | 역할 |
| --- | --- | --- |
| Assets/Scripts/Telemetry | TelemetryManager, TelemetryStageRecorder, TelemetryFileWriter | 세션·구간·수집·큐·저장·정상 종료 |

#### 연결 및 협업

- 연결된 기능: 플레이어·카타나 V2·적 공격·보스·씬 공통 초기화·재도전·씬 전환.
- 공유하는 코드 및 상태: 기존 입력·체력·방어 이벤트와 배치 프리팹을 사용한다. 전투 TargetId는 유지한다.
- 중복 또는 충돌 사항: 기존 로깅 기능 없음. 승인된 설계에 필요한 코드와 에셋에만 연결한다.
- 승인 필요 사항 및 결과: 사용자가 설계 검토 후 그대로 구현하도록 승인했다. feature/log 브랜치에서는 Git CLI 및 커밋을 수행하지 않는다.

#### 데이터 계약 및 검증

- 적 공격 이벤트는 종류별 파일에 enemy_id, elapsed_real_seconds, position만 저장한다.
- 입력 횟수는 실제 새 누름, 성공은 최종 판정으로 집계한다. 방어는 DefenseSucceeded 한 경로를 사용한다.
- 원거리 스냅샷 bool은 직전 수집 이후 사건 래치다. 누락은 큐 밖 카운터에 남기며 중요 이벤트 포화는 Failed다.
- 검증: 미확인. 테스트 코드는 작성하지 않는다.
